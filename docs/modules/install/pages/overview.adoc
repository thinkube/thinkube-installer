= Install Thinkube
:page-type: concept

_What you need to install Thinkube, and the order to do it in._

.TL;DR
Get the installer, prepare one machine, have your accounts and tokens ready, then run the installer. More machines join after the install.

== The steps

. xref:get-the-installer.adoc[Get the installer] — a desktop application for Ubuntu 24.04.
. xref:node-setup.adoc[Prepare your machines] — Ubuntu Server 24.04, a user with sudo, SSH and internet access. The first machine becomes the control plane.
. Have your accounts and tokens ready:
** xref:overlay-network.adoc[Connect from anywhere] — a Tailscale account and its keys.
** xref:cloudflare-token.adoc[Set up your domain] — a domain at Cloudflare and an API token.
** xref:github-token.adoc[Connect to GitHub] — a GitHub personal access token.
** xref:huggingface-token.adoc[Unlock AI models] — a Hugging Face access token.
** Optional: an Anthropic account for Claude Code, which is a paid service. Thinkube installs Claude Code from Anthropic's official installer; you sign in with your own account the first time you start it in Thinkube IDE.
. xref:run-the-installer.adoc[Run the installer] — the installer, screen by screen, and what each screen does to your machine.
. xref:adding-nodes.adoc[Add more nodes] — from Thinkube Control, after the install.

Thinkube is alpha software: a new version may need a fresh install, so install it on machines you can reinstall.
